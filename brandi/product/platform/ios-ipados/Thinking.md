| Field | Spec |
|---|---|
| Native control | None. The closest pattern is an activity indicator beside text [APL-2]. |
| Target and spacing | Nothing here is pressed, so no hit area applies. Any control inside meets the 44 × 44 pt default and the 28 × 28 pt minimum [APL-1]. |
| Type | SF Pro through a text style, so it follows Dynamic Type [APL-3]. At large sizes, stack secondary items under the text instead of truncating [APL-3]. |
| Colour and theme | Text takes the system label colours, which adapt to both appearances [APL-5]. Every custom colour needs light and dark variants, each with an increased-contrast option [APL-4]. |
| States | Working, then replaced by the result. The words carry the status, so motion is never the only signal [APL-6]. |
| Motion | Under reduced motion the product slows the spinner rather than stopping it [APL-1] [APL-24]. No pulsing dots: the words carry the status [APL-6]. |
| Accessibility API | VoiceOver. With `live` on, post an `AccessibilityNotification` when the line changes [APL-19]. Inside something with its own status line, post nothing. The spinner is hidden [APL-19]. |
| Navigation placement | Where the answer will appear, near the content it affects [APL-20]. |
| Keyboard, pointer, trackpad | Not a focus target. iPadOS keyboard focus covers content elements such as list items, text fields and search fields, and Full Keyboard Access covers controls [APL-15] [APL-16]. |
| Haptics | None specified for the working line. Apple names system haptics for toggles, sliders and pickers, and feedback generators for notification, impact and selection [APL-18]. |
| Brand may change | The wording, which names the work ("Reading 12 [records]"), never "Thinking…" alone once the work is known. In the brand's voice [APL-8]. |
| Platform owns | Reduce Motion, which people set [APL-24]. |
| Not confirmed | The activity indicator API. |
