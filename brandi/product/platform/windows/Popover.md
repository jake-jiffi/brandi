| Field | Spec |
|---|---|
| Native control | WinUI `Flyout` [WIN-12], attached to a button's `Flyout` property [WIN-13]. |
| Target and spacing | Its controls take the 40 × 40 px touch target [WIN-2]. 8 epx between the button and its flyout [WIN-4]. |
| Type | Segoe UI Variable, Body 14 on 20 epx [WIN-5] [FLU-3]. Text scales from 100% to 225%, and WinUI text controls follow it by default [WIN-6]. |
| Colour and theme | Corners 8 px through `OverlayCornerRadius`, square on the side joined to its trigger [WIN-12]. In contrast themes, `SystemColorWindowColor` with a 2 px border [WIN-9]. |
| States | Open or closed, like any transient UI [WIN-17]. |
| Motion | Enter and exit [FLU-5]. Surfaces that share an entry point open and close the same way [WIN-10]. Check `UISettings.AnimationsEnabled` [WIN-11]. |
| Accessibility API | Narrator through UI Automation. The trigger is a button named by its action [WIN-19] [WIN-20]. Focus must not be lost when it closes [FLU-4]. |
| Navigation placement | Anchored to its trigger. Set `Placement`, since the default may not land where intended [WIN-13]. |
| Keyboard, pointer, trackpad | Enter or Space on the trigger opens it [WIN-13], and Esc closes it [WIN-17]. |
| Haptics | None specified. WinUI 3 apps can use OS touchpad and mouse haptics through `Windows.Devices.Haptics` from Windows App SDK 2.4.0, where the OS and hardware support them [WIN-25]. When to play one: not confirmed. |
| Brand may change | Hover shows a definition after a short delay, a press, a tap or Enter opens it, Escape or a press elsewhere closes it, and focus returns to the trigger. Opening on hover goes beyond a button's click-to-open flyout [WIN-13], and the product's guidelines apply (2.3). |
| Platform owns | Esc and the rules for transient UI [WIN-17]. |
| Not confirmed | Dismissing on a press elsewhere. Focus return to the trigger. Opening a flyout on hover. Haptic guidance. |
