| Field | Spec |
|---|---|
| Native control | WinUI `CheckBox` [WIN-12] [WIN-13]. |
| Target and spacing | Touch target 7.5 mm, which is 40 × 40 px at 135 PPI and 1.0x scale [WIN-2]. 12 epx between the box and its label [WIN-4]. |
| Type | Label in Body, 14 on 20 epx [WIN-5] [FLU-3]. Sentence case for all UI text [WIN-5]. The label wraps as text scales [WIN-6]. |
| Colour and theme | Accent shows the checked state [WIN-7]. In contrast themes, `SystemColorHighlightColor` with `SystemColorHighlightTextColor` when checked, and `SystemColorGrayTextColor` when disabled [WIN-9]. Corners 4 px through `ControlCornerRadius` [WIN-12]. |
| States | Checked and unchecked, plus disabled, which leaves the tab order [WIN-18]. Keyboard focus draws a 2 px outer and 1 px inner border, 1 px outside the control [WIN-3]. The indeterminate state's drawing: not confirmed. |
| Motion | Use WinUI's built-in control motion and avoid custom animation [WIN-10]. Check `UISettings.AnimationsEnabled`, which reports whether animations are on [WIN-11]. |
| Accessibility API | Narrator through UI Automation. Name from its visible label [WIN-19]. Its control type and how the checked state is exposed: not confirmed. |
| Navigation placement | Forms, in page content. The touch keyboard stays open when focus moves here from a text field [WIN-17]. |
| Keyboard, pointer, trackpad | Space toggles the focused box [WIN-17]. Tab moves to the next control [WIN-17]. |
| Haptics | None specified. WinUI 3 apps can use OS touchpad and mouse haptics through `Windows.Devices.Haptics` from Windows App SDK 2.4.0, where the OS and hardware support them [WIN-25]. When to play one: not confirmed. |
| Brand may change | A label that states the outcome ("Email the [client] a copy"), and a Switch instead when the setting applies at once. Both keep Microsoft's touch target [WIN-2]. |
| Platform owns | Space to toggle [WIN-17]. Contrast theme colours [WIN-9]. |
| Not confirmed | `CheckBox`'s UI Automation control type and patterns. How the indeterminate state is drawn. Visual state names. Haptic guidance. |
