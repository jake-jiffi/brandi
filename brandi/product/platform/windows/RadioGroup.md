| Field | Spec |
|---|---|
| Native control | WinUI `RadioButtons` [WIN-17], or individual `RadioButton`s [WIN-13]. |
| Target and spacing | Each option takes the 40 × 40 px touch target [WIN-2]. 12 epx between a button and its label [WIN-4]. |
| Type | Segoe UI Variable, Body 14 on 20 epx [WIN-5] [FLU-3]. Sentence case for all UI text [WIN-5]. Labels wrap as text scales [WIN-6]. |
| Colour and theme | Accent shows the chosen state [WIN-7]. In contrast themes, the highlight pair for the chosen option and `SystemColorGrayTextColor` for disabled ones [WIN-9]. |
| States | Chosen, not chosen and disabled, per option. Disabled options leave the tab order [WIN-18]. |
| Motion | Use WinUI's built-in control motion and avoid custom animation [WIN-10]. Check `UISettings.AnimationsEnabled`, which reports whether animations are on [WIN-11]. |
| Accessibility API | Narrator through UI Automation. Each option is named by its label [WIN-19]. How the group's legend reaches Narrator, and each option's control type: not confirmed. |
| Navigation placement | Forms, in page content. The touch keyboard stays open when focus moves to a radio button [WIN-17]. |
| Keyboard, pointer, trackpad | One tab stop for the group, arrow keys between options, Home to the first and End to the last [WIN-17]. |
| Haptics | None specified. WinUI 3 apps can use OS touchpad and mouse haptics through `Windows.Devices.Haptics` from Windows App SDK 2.4.0, where the OS and hardware support them [WIN-25]. When to play one: not confirmed. |
| Brand may change | A legend, the safest or most common option preselected, and more than five options moving to a Select. Microsoft's one-tab-stop group is the keyboard model [WIN-17]. |
| Platform owns | The group's keyboard model [WIN-17]. Contrast theme colours [WIN-9]. |
| Not confirmed | How the legend reaches UI Automation. Whether arrow keys also change the choice. Each option's control type. Haptic guidance. |
