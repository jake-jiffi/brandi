# Toolbar on Android

On Android, Toolbar is one row of search, filters and view controls above a table or list, wrapping on narrow windows.

| Field | Spec |
|---|---|
| Native control | A docked row in the content. Material's toolbars display frequently used actions for the current page [MAT-4]. Compose's `HorizontalFloatingToolbar`, out of experimental status in the 1.5.0 pre-releases, floats instead [AND-9]. |
| Target and spacing | Every control keeps at least 48 × 48 dp, with 8 dp or more between targets [MAT-7]. |
| Type | Roboto is the default for both the brand and the plain typeface [MAT-16]. Text in sp, scaled nonlinearly up to 200% since Android 14 [AND-5]. |
| Colour and theme | One set of colour roles serves light and dark [MAT-18]. Medium contrast (3:1) and high contrast (7:1) arrive through the same roles [MAT-18]. Text keeps 4.5:1 below 18 sp, or below 14 sp in bold, and 3:1 otherwise [AND-1]. |
| States | Filters, or bulk actions once rows are selected, by the product's rule. Its controls carry their own states [MAT-9]. |
| Motion | Material motion runs on springs, in an expressive or a standard scheme [MAT-17]. People can turn on Remove animations [AND-10]. `ValueAnimator.areAnimatorsEnabled()` returns false when the animator duration scale is 0 or Battery Saver is on [AND-6]. Whether Remove animations sets that scale is not confirmed. |
| Accessibility API | Its controls read in the layout's top-down order [MAT-7]. How a row of controls carries a group name such as "[Record] filters" for TalkBack is not confirmed. An offscreen Compose toolbar no longer takes keyboard focus since the 1.5.0 pre-releases [AND-9]. |
| Navigation placement | Above its table as one block that sticks while the table scrolls, 12 px above it in the web build and not converted here, by the product's rule. Material's toolbars hold the page's frequent actions [MAT-4]. |
| Keyboard, pointer, trackpad | Its controls take focus in reading order [MAT-7]. Keyboard focus shows Material's ring-like focus indicator [MAT-9]. |
| Haptics | None. On Android less is more with haptics, and no haptic beats a buzzy one [AND-3]. |
| Brand may change | Search first, then filter chips, a Spacer, then the view switcher and secondary actions. Selecting rows swaps the filters for bulk actions. Material's floating toolbar [AND-9] is not used here. |
| Platform owns | How TalkBack merges nodes and phrases them [AND-2]. Text scaling, nonlinear to 200% [AND-5]. |
| Not confirmed | Motion: whether Remove animations sets the animator duration scale that `areAnimatorsEnabled()` reads. Accessibility API: how a row of controls carries a group name for TalkBack. |
