# Board on Android

| Field | Spec |
|---|---|
| Native control | None. Material 3 has no board component [MAT-4]. Columns of Material cards [MAT-4], with dragging backed by custom actions [AND-2]. |
| Target and spacing | Each card and its "Move to" button keep at least 48 × 48 dp [MAT-7]. |
| Type | Card titles and meta lines as on ListRow, in body large and body medium [MAT-20] [MAT-16]. Roboto is the default for both the brand and the plain typeface [MAT-16]. Text in sp, scaled nonlinearly up to 200% since Android 14 [AND-5]. |
| Colour and theme | One set of colour roles serves light and dark [MAT-18]. Medium contrast (3:1) and high contrast (7:1) arrive through the same roles [MAT-18]. Text keeps 4.5:1 below 18 sp, or below 14 sp in bold, and 3:1 otherwise [AND-1]. |
| States | Cards take hovered, focused, pressed and dragged states, and can lift while dragged [MAT-9]. System state layers: 8% for hover, 10% for focus and press, 16% for drag [MAT-5]. |
| Motion | A dragged card lifts [MAT-9]. People can turn on Remove animations [AND-10]. `ValueAnimator.areAnimatorsEnabled()` returns false when the animator duration scale is 0 or Battery Saver is on [AND-6]. Whether Remove animations sets that scale is not confirmed. |
| Accessibility API | Each card is one node, with "Move to" in its menu and also as a custom action [AND-2]. Each column reports its size with `collectionInfo` [AND-2], and its count as words. |
| Navigation placement | Columns side by side, scrolling sideways when they do not fit, by the product's rule. How many show at compact widths is not confirmed. Material repositions content as breakpoints change [MAT-10]. |
| Keyboard, pointer, trackpad | Cards take focus [MAT-9], and the "Move to" menu moves a card from the keyboard, by the product's rule. A key map for the board as a whole is not confirmed. |
| Haptics | `DRAG_START`, from API 34, marks the moment a dragged card is picked up [AND-4]. |
| Brand may change | A card follows ListRow's title, meta line and badge rules. Column counts follow NavItem: highlight for the reader, grey for others, nothing at zero. Unproven: no review round has checked it. The product's typefaces replace Roboto [MAT-16]. |
| Platform owns | How TalkBack merges nodes and phrases them [AND-2]. |
| Not confirmed | Motion: whether Remove animations sets the animator duration scale that `areAnimatorsEnabled()` reads. Navigation placement: how many columns show at compact widths. Keyboard, pointer, trackpad: a key map for the board as a whole. |
