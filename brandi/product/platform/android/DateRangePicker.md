# DateRangePicker on Android

| Field | Spec |
|---|---|
| Native control | Material date pickers, which select a date or a range of dates [MAT-4]: Compose `DateRangePicker` [AND-9]. |
| Target and spacing | Each day and control at least 48 × 48 dp [MAT-7]. |
| Type | Roboto is the default for both the brand and the plain typeface [MAT-16]. Text in sp, scaled nonlinearly up to 200% since Android 14 [AND-5]. Material's text styles for the picker are not confirmed. |
| Colour and theme | One set of colour roles serves light and dark [MAT-18]. Medium contrast (3:1) and high contrast (7:1) arrive through the same roles [MAT-18]. Text keeps 4.5:1 below 18 sp, or below 14 sp in bold, and 3:1 otherwise [AND-1]. The range shows its ends and its span with more than colour, by the product's rule. |
| States | Date pickers take hovered and focused states [MAT-9]. Start, end, in range and disabled days, by the product's rule. |
| Motion | Material motion runs on springs, in an expressive or a standard scheme [MAT-17]. People can turn on Remove animations [AND-10]. `ValueAnimator.areAnimatorsEnabled()` returns false when the animator duration scale is 0 or Battery Saver is on [AND-6]. Whether Remove animations sets that scale is not confirmed. |
| Accessibility API | The month and year title is no longer conveyed as actionable to screen reader, Switch Access and Voice Access users since a fix [AND-9]. The roles and states `DateRangePicker` gives each day are not confirmed. |
| Navigation placement | In a dialog or inline in a report's controls, by the product's rule. Material uses basic dialogs for date pickers [MAT-14]. |
| Keyboard, pointer, trackpad | Tab moves focus in and out of the dates, and the arrow keys move through them, since a fix for a focus trap in the 1.5.0 pre-releases [AND-9]. |
| Haptics | None. On Android less is more with haptics, and no haptic beats a buzzy one [AND-3]. |
| Brand may change | A period says what it is compared with ("vs last month"), and typing a range always works. Material's date picker dialog confirms with OK [MAT-14], where the product never labels a button "OK". Unproven: no review round has checked it. |
| Platform owns | How TalkBack merges nodes and phrases them [AND-2]. |
| Not confirmed | Type: Material's text styles for the picker. Motion: whether Remove animations sets the animator duration scale that `areAnimatorsEnabled()` reads. Accessibility API: the roles and states `DateRangePicker` gives each day. |
