# PhoneTopBar on Android

| Field | Spec |
|---|---|
| Native control | Material app bars, placed at the top of the screen [MAT-4]: Compose `TopAppBar`, out of experimental status in the 1.5.0 pre-releases [AND-9]. |
| Target and spacing | Back and any actions keep the 48 dp minimum of `IconButton` [AND-1]. |
| Type | Roboto is the default for both the brand and the plain typeface [MAT-16]. Text in sp, scaled nonlinearly up to 200% since Android 14 [AND-5]. Long titles wrap rather than overflow, by the product's rule, and Compose keeps a `TopAppBar` title from overlapping the actions since a fix [AND-9]. |
| Colour and theme | One set of colour roles serves light and dark [MAT-18]. Medium contrast (3:1) and high contrast (7:1) arrive through the same roles [MAT-18]. Text keeps 4.5:1 below 18 sp, or below 14 sp in bold, and 3:1 otherwise [AND-1]. |
| States | An app bar takes no hover, focus, press or drag state as a whole. Back and the actions do [MAT-9]. |
| Motion | Since Android 14 apps can opt in to predictive back animations per activity, with `android:enableOnBackInvokedCallback` [AND-5]. People can turn on Remove animations [AND-10]. `ValueAnimator.areAnimatorsEnabled()` returns false when the animator duration scale is 0 or Battery Saver is on [AND-6]. Whether Remove animations sets that scale is not confirmed. |
| Accessibility API | Its title takes `Modifier.semantics { heading() }`, so TalkBack can jump between headings [AND-2]. Back is `Role.Button`, named "Back" [AND-1]. After navigating, focus moves to the new screen's content, by the product's rule. The Compose API for moving focus is not confirmed. |
| Navigation placement | The top of the screen [MAT-4], on phones, where list and detail become two screens, by the product's rule. |
| Keyboard, pointer, trackpad | Back and the actions take Tab, then Space or Enter [MAT-6]. Focus ring 3 dp thick, 2 dp outside, in `secondary` [MAT-5]. |
| Haptics | None. On Android less is more with haptics, and no haptic beats a buzzy one [AND-3]. |
| Brand may change | Back and the screen's title, with long names wrapping rather than overflowing. Unproven: no review round has checked it. Material's top app bar is the closest match [MAT-4]. |
| Platform owns | The system back gesture and its predictive animation [AND-5]. How TalkBack merges nodes and phrases them [AND-2]. |
| Not confirmed | Motion: whether Remove animations sets the animator duration scale that `areAnimatorsEnabled()` reads. Accessibility API: the Compose API for moving focus. |
