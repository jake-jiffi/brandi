# Conversation on Android

| Field | Spec |
|---|---|
| Native control | None as a Material component [MAT-4]. The messages as a list [MAT-20] and a composer built on a Material text field [MAT-4]. |
| Target and spacing | The composer, Send and any message actions keep at least 48 × 48 dp [MAT-7]. |
| Type | Roboto is the default for both the brand and the plain typeface [MAT-16]. Text in sp, scaled nonlinearly up to 200% since Android 14 [AND-5]. Material suggests its "emphasized" styles for unread messages [MAT-16]. |
| Colour and theme | A message from the assistant carries the `ai` tone, by the product's rule. Text keeps 4.5:1 below 18 sp, or below 14 sp in bold, and 3:1 otherwise [AND-1]. |
| States | Unread and read, and sending, sent and failed, by the product's rule. The composer takes text field states [MAT-9]. |
| Motion | Material motion runs on springs, in an expressive or a standard scheme [MAT-17]. People can turn on Remove animations [AND-10]. `ValueAnimator.areAnimatorsEnabled()` returns false when the animator duration scale is 0 or Battery Saver is on [AND-6]. Whether Remove animations sets that scale is not confirmed. |
| Accessibility API | A new message is announced politely, once [AND-2]. Each message reads who sent it, when, and its text, as one node [AND-2], and an unread one adds "(unread)" [AND-2]. The thread itself is not a live region. |
| Navigation placement | The content area, with the composer at the foot, by the product's rule. Material places nothing like it [MAT-4]. |
| Keyboard, pointer, trackpad | Keyboard focus shows Material's ring-like focus indicator [MAT-9]. How Enter sends from a Compose text field is not confirmed. |
| Haptics | None. On Android less is more with haptics, and no haptic beats a buzzy one [AND-3]. |
| Brand may change | Every message names who sent it and when, and the composer's label says what the text is for. The assistant's own thread is the AskPanel. Unproven: no review round has checked it. The product's typefaces replace Roboto [MAT-16]. |
| Platform owns | How TalkBack merges nodes and phrases them [AND-2]. |
| Not confirmed | Motion: whether Remove animations sets the animator duration scale that `areAnimatorsEnabled()` reads. Keyboard, pointer, trackpad: how Enter sends from a Compose text field. |
